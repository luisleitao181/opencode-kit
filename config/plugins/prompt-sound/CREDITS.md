## sound.mp3

The recording is "Whip-sound" by **Mike Koenig** (SoundBible), published on
Wikimedia Commons:

- Source: <https://commons.wikimedia.org/wiki/File:Whip-sound.ogg>
- Original: <http://soundbible.com/1150-Whip.html>
- License: **CC BY 3.0** (<https://creativecommons.org/licenses/by/3.0/>)
- File used here: the MP3 transcode from Commons (`Whip-sound.ogg.mp3`),
  because OpenCode's audio engine decodes WAV/FLAC/MP3 but not Vorbis.

Attribution is required if this file is redistributed. `scripts/fetch-mp3.py`
re-downloads it; `scripts/fetch-mp3.py --check` re-validates the local copy.
